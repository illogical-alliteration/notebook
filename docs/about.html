About Javascript Notebook

Introduction

Welcome to the about page for apps.verticesandedges.net/notebook. On this page, you'll find links to the privacy policy and terms of use, as well as a short description of the notebook's features.

Javascript Notebook is a Jupyter-style notebook, for browser side Javascript and Typescript. It does not send commands to a server and return the results to the notebook. Rather your commands are executed in your browser, and (unless you choose to save them via URL) never leave your computer.

Howto

The Javascript Notebook has three types of cells:

  • Markdown Cells
  • Typescript Cells
  • Javascript Cells
You can switch between them at will.

The Markdown Cell uses a live preview library (codemirror-live-markdown), which means you can just start typing markdown syntax, and it will render as you go. Beginning a line with "#" turns it into a header 1, beginning it with "##" turns it into a header 2, and so on. You can create links using "[display text](url)" syntax. To render math formulas using KaTeX, insert a code block by starting with three backticks, the word math, a new line your math formula and closing with three backticks. Like this: 

```math
E = m c^2
```
which will render the square as a superscript to c as we're used to.

Typescript and Javascript cells (aka Code Cells) are executed as AsyncFunctions. They are functions, so to see a result use a "return xyz" statement", which also supports HTMLElements by simply appending them to the result output element. console.log and console.error are also supported.
